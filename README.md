# Extrator Multi-Grupos (WhatsApp API)

Script para mapeamento da matriz de participantes de vários grupos, realizando agregação de origens e deduplicação em memória RAM antes de efetuar consultas individuais de estado, economizando requisições de rede.


## Dependências: 
Node.js (v16+), whatsapp-web.js, qrcode-terminal, e fs.
